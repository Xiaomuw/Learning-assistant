## 5. 半自动化命令（先行执行版）

> 以环境变量替换：
> `FRONTEND`、`API`、`EMAIL`、`PASSWORD`、`USER_ID`、`PDF_PATH`

```bash
export FRONTEND="http://127.0.0.1:3000"
export API="http://127.0.0.1:8000/api"
export EMAIL="user@example.com"
export PASSWORD="YourPassword123!"
export USER_ID="<USER_ID>"

# 1) 鉴权与重定向
curl -I -s -o /tmp/h5_root.headers "$FRONTEND/" | awk 'NR==1{print}'
grep -i "location\|http_code" /tmp/h5_root.headers

# 2) 登录页静态校验（仅做“页面可回显”）
curl -sS "$FRONTEND/login" -o /tmp/h5_login.html
[ -s /tmp/h5_login.html ] && echo "login page ok"

# 3) API 登录（示例）
curl -i -sS -X POST "$API/auth/login" \
  -H 'Content-Type: application/json' \
  -d '{"email":"'"$EMAIL"'","password":"'"$PASSWORD"'"}'

# 4) 主页面直达（带 cookie 文件）
COOKIE_FILE="/tmp/h5.cookies"
curl -I -sS "$FRONTEND/chat" -H "Cookie: $(cat "$COOKIE_FILE" 2>/dev/null || true)"
curl -I -sS "$FRONTEND/practice" -H "Cookie: $(cat "$COOKIE_FILE" 2>/dev/null || true)"
curl -I -sS "$FRONTEND/dashboard" -H "Cookie: $(cat "$COOKIE_FILE" 2>/dev/null || true)"
curl -I -sS "$FRONTEND/profile" -H "Cookie: $(cat "$COOKIE_FILE" 2>/dev/null || true)"

# 5) H5 聊天流（SSE 直答）
curl -N -sS -X POST "$FRONTEND/api/chat" \
  -H 'Content-Type: application/json' \
  -H "Cookie: $(cat "$COOKIE_FILE" 2>/dev/null || true)" \
  -d '{"user_id":"'"$USER_ID"'","question":"1+1 等于几？","notebook_id":"data-structure","allow_web":false}'

# 6) H5 聊天流（联网）
curl -N -sS -X POST "$FRONTEND/api/chat" \
  -H 'Content-Type: application/json' \
  -H "Cookie: $(cat "$COOKIE_FILE" 2>/dev/null || true)" \
  -d '{"user_id":"'"$USER_ID"'","question":"今天深圳有什么值得关注的新闻？","notebook_id":"data-structure","allow_web":true}'

# 7) sync + 轮询（移动补充）
SYNC_RES=$(curl -sS -X POST "$API/chat/sync" \
  -H 'Content-Type: application/json' \
  -H "Cookie: $(cat "$COOKIE_FILE" 2>/dev/null || true)" \
  -d '{"user_id":"'"$USER_ID"'","question":"今天上海的天气如何？","allow_web":true,"client_request_id":"h5-e2e-fixed-id","notebook_only":false}')
echo "$SYNC_RES" | sed 's/[{}"\[\](),]//g'
JOB_ID=$(echo "$SYNC_RES" | sed -n 's/.*"job_id":"\([^"]*\)".*/\1/p')
if [ -n "$JOB_ID" ]; then
  curl -sS -X GET "$API/chat/jobs/$JOB_ID" | sed 's/[{}"\[\](),]//g'
  curl -sS -X POST "$API/chat/jobs/$JOB_ID/poll" -H 'Content-Type: application/json'
fi
```

> 上述仅是“抓痕迹模板”。建议将上述每步输出保存到本地 `*.log` 并与截图绑定，按用例贴到执行记录中。

## 6. 阻塞项记录（用于验收前）
1. H5 页面与 API 任何链路出现 5xx、超时或白屏立即阻塞为 P1。
2. `/help` 若返回 404，先标记为历史文档残留差异，不直接作为核心功能阻塞。
3. 会话/练习/同步链路若出现“无用户提示、无重试入口、重复提交”，直接升级为 P0。
4. 移动端同步链路：`GET /api/chat/jobs/{id}/poll` 返回 `405 Method Not Allowed`，正式验证必须使用 `POST` 进行轮询。
5. H5-020 上传链路可返回成功但未映射到知识片段（`mapped_chunks=0`），需要确认是否系统设计即允许“入库成功但不参与检索”。
6. H5-MOB 过期路径 (`expired`) 未在本轮环境触发到，建议补测以覆盖 5xx/过期提示。
